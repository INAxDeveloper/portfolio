How to get a GitHub Personal Access Token (PAT):
  1. Visit github.com/settings/tokens/new (GitHub Developer Settings).
  2. Give note name: Portfolio-Admin-Panel and choose Expiration (e.g. 90 days or No expiration).
  3. Check the repo scope checkbox (Full control of private repositories & commit access).
  4. Click Generate token at the bottom, then copy the token (starts with ghp_) and paste it into the input above.
